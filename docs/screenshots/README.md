# Screenshot contribution guide

There are currently no screenshots of the running application in this repository.

When adding screenshots, capture the real application and save the image in this directory. Before committing, review the image for private notes, recordings, usernames, file paths, device names, notifications, or other personal data and remove or obscure anything sensitive. Do not add generated mockups as screenshots of the application.

Embed a reviewed screenshot in the root README with a repository-relative path, for example:

```markdown
![VoiceThoughtCapture tray menu](docs/screenshots/tray-menu.png)
```
